# FM радиоприемник на FM1216ME
*Проект создан исключительно с академической целью.*

## Технические характеристики
* Частотный диапазон: 65.90 - 108.00 MHz
* Напряжение питания: 9 - 12 V
* Ток потребления: 270 mA

## Органы управления
* Энкодер SW1: Вращение энкодера изменяет частоту радиоприемника
* Нажатие кнопки энкодера SW1: Запуск сканирования FM диапазона
* Нажание кнопки SW2: Перечитать информационные биты FM1216ME и вывести в USART

## Основные компоненты
* FM1216ME/IH-5
* PIC16F876A
* HD44780
* PCF8574T
* MAX232CPE

## Отладка через URAST
Радиоприемник предоставляет следующую информацию через протол RS232:
```
********* FM1216ME DEBUG BOARD *********
****************************************
            FM FREQ: 92.80MHz
****************************************
********** TUNER STATUS BIT ************
POR:   0
FL:    1
AGC:   1
SOUND: 1
************ IF STATUS BIT *************
VIFL:  1
FMIFL: 0
AFC:   13
*****************************************
```
Подключение к PC осуществлется через COM-порт.
Для соединения с радиоприемником можно использовать minicom `minicom -D /dev/ttyS0 -b 9600`
